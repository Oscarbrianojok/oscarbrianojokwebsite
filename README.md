# Oscar Brian Ojok | Personal Portfolio Website

Official personal portfolio website of **Oscar Brian Ojok**, a civil engineer, climate-tech entrepreneur, and social innovator based in Uganda.

The website provides information about my professional background, initiatives, projects, expertise, achievements, and publications.

## Website Sections

- **Home:** Professional introduction and overview.
- **About Me:** Background, experience, education, and media publications.
- **My Work:** Initiatives and projects, including Ecoflash and Innovate2day Societas.
- **Expertise:** Professional skills and areas of specialisation.
- **Recognition:** Awards and professional achievements.
- **Blog:** Articles and insights.
- **Moments:** Photographs from activities and events.
- **Contact:** Contact information and professional enquiries.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

To run the website locally:

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

The website is built as a static site and does not require a backend server.
